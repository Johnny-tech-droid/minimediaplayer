# MiniMediaPlayer

A small media player for MP3 and MP4 files, built with **JavaFX 21** and **FXML** (learning project from my Java course). Play/pause, stop, mute and volume controls with Ikonli icons.

## Requirements

- JDK 21

## Run

```bash
./mvnw clean javafx:run
```

Use *Open* to pick an `.mp3` or `.mp4` file; the file dialog starts in your home folder.
